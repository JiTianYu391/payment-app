结账流程

SpacePay 托管结账页：商户创建支付后把 checkout_url 交给付款人，付款人登录并输入支付 PIN 完成付款。商户服务端不需要接触付款人的密码或 PIN。

完整流程

服务端创建支付

调用 POST /api/v1/payments，得到 payment.id 与 checkout_url。

浏览器跳转

把付款人浏览器重定向到 checkout_url。页面会显示商户、金额与描述。

付款人登录并确认

未登录时先登录 SpacePay；已登录则输入 6 位支付 PIN 并确认付款。

服务端收到 Webhook

付款成功推送 payment.succeeded；校验签名后发货。

浏览器跳回

付款成功跳到 success_url，取消跳到 cancel_url。

!不要用浏览器跳回 success_url 作为支付成功的依据——跳转可能被关闭、网络中断或被伪造。以 Webhook 为准。

如何跳转

// 创建支付后，把地址返回给前端，由前端跳转
const resp = await fetch('https://your-domain/api/v1/payments', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${process.env.SPACEPAY_KEY}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({ amount: '12.34', reference: 'order-2026-0001' }),
});
const { payment } = await resp.json();
res.redirect(payment.checkout_url);
import os
import requests
from flask import redirect

resp = requests.post(
    "https://your-domain/api/v1/payments",
    headers={"Authorization": f"Bearer {os.environ['SPACEPAY_KEY']}"},
    json={"amount": "12.34", "reference": "order-2026-0001"},
    timeout=15,
)
payment = resp.json()["payment"]
return redirect(payment["checkout_url"])
# 创建支付并取出结账链接
URL=$(curl -s -X POST https://your-domain/api/v1/payments \
  -H "Authorization: Bearer $SPACEPAY_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"amount":"12.34","reference":"order-2026-0001"}' \
  | python3 -c "import sys,json;print(json.load(sys.stdin)['payment']['checkout_url'])")
echo "$URL"

付款

POST/api/checkout/:token/pay需要付款人登录 + 支付 PIN

请求体：{"pin":"123456"}。成功返回支付单、付款后余额与 success_url。

  • 未登录返回 401 UNAUTHENTICATED；结账页会先跳转登录：/?next=/pay.html?token=…。
  • 支付单设置了 customer_email 时，其他账户付款返回 403 CUSTOMER_MISMATCH。
  • PIN 错误返回 403 PIN_INCORRECT；连续错误会锁定并返回 423 PIN_LOCKED。

取消

POST/api/checkout/:token/cancel需要付款人登录

把支付单置为 CANCELED。已支付的支付单不能取消，返回 409 PAYMENT_NOT_CANCELABLE。

成功与取消地址

字段行为
success_url付款成功后结账页跳转的地址；未设置时停留在成功页
cancel_url付款人取消后跳转的地址；未设置时停留在取消页

这两个地址只影响浏览器体验，不影响支付状态。不要在这两个页面执行发货、加余额等不可逆操作。

有效期与失败处理

  • 支付单创建后 30 分钟内有效，过期后结账页显示「链接已过期」，需要重新创建。
  • 商户被暂停时，结账页不能付款（MERCHANT_INACTIVE）。
  • 同一支付单只能成功付款一次；重复付款返回 409 PAYMENT_NOT_PAYABLE。
i如果你想在自己的页面内完成支付，需要自行处理登录会话、PIN 输入与错误提示。建议直接使用托管的 checkout_url，减少合规与实现成本。
