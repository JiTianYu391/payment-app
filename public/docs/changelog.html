开放平台接口、Webhook 与文档的变更记录。破坏性变更会提前标注。

2026-11-11 · v4.0.0

首个公开版本，包含完整的商户接入能力。

接口

  • POST /api/v1/payments 创建支付，支持 Idempotency-Key 与 reference 去重。
  • GET /api/v1/payments/:id 查询支付与退款记录。
  • GET /api/v1/payments 游标分页列表，支持按状态筛选。
  • POST /api/v1/payments/:id/refund 部分或全额退款。
  • GET /api/v1/balance 可结算余额与在途结算。
  • GET/POST /api/v1/payouts 结算提现申请与记录。
  • 结账接口：GET /api/checkout/:token、POST /api/checkout/:token/pay、POST /api/checkout/:token/cancel。

Webhook

  • 事件 payment.succeeded 与 payment.refunded。
  • HMAC-SHA256 签名（X-SpacePay-Signature），6 次指数退避重试，后台可手动重投。
  • 投递前解析域名并拒绝内网目标。

商户后台与安全

  • 商户入驻审核、API Key 创建与吊销、Webhook 配置、支付与结算管理。
  • API Key 只保存哈希；每个 Key 独立限流；请求日志可追溯。
  • 付款人使用 httpOnly 会话与支付 PIN，可选 TOTP 两步验证。

文档

  • 文档站上线：快速开始、接口参考、Webhook、错误码、限流与幂等、密钥安全。
  • 所有接口提供 curl / Python / Node.js 示例。

兼容性说明

  • 接口路径与字段遵循语义化版本：新增字段属于兼容变更，删除或改名会提升主版本并在本页标注。
  • 金额字段同时提供整数分（*_cents）与十进制字符串，建议以整数分为准。
  • 错误响应的 code 是稳定标识，error 文案可能优化，请不要依赖文案匹配。
