更新日志

开放平台接口、Webhook 与文档的变更记录。破坏性变更会提前标注。

2026-11-18 · v4.1.0

行为变更（不兼容旧行为）

  • 商户收款默认即时到账：新商户的 settlement_mode 默认为 auto，付款成功后钱直接进商户所有者账户余额，/api/v1/balance 的 available_cents 恒为 0。需要原来的「先待结算、再申请提现」流程时，在商户后台或 PATCH /api/merchant/profile 设 settlement_mode: "manual"。
  • 退款扣款账户随之改变：auto 的订单从商户账户余额扣回，manual 的订单从可结算余额扣。余额不足都返回 INSUFFICIENT_MERCHANT_BALANCE。
  • 支付单新增 settle_mode：记录该笔实际的到账方式，切换模式不会改动历史订单。
  • 新增交易类型：sale（经营收入，入账商户账户）与 merchant_refund_out（退款支出）。

新增

  • 收款二维码：创建支付与查询支付时返回 payment.qr 与 payment.qr_svg；新增公开接口 GET /api/checkout/:token/qr 与 GET /api/checkout/:token/qr.svg，支持 size 参数。详见 收款二维码。
  • 扫码付款：App 新增「扫一扫」（首页快捷操作、顶栏和 /scan），支持相机扫码、相册选图与粘贴链接。
  • 支付 PIN 输入重做：6 格分段显示、数字键盘、支持粘贴与密码管理器，输错时抖动并清空。
  • 手机端运营后台入口：底部标签栏「运营」+「我的 → 运营后台」菜单 + 窄屏横向板块切换。此前侧栏在窄屏隐藏，管理员在手机上找不到后台。

2026-11-11 · v4.0.0

首个公开版本，包含完整的商户接入能力。

接口

  • POST /api/v1/payments 创建支付，支持 Idempotency-Key 与 reference 去重。
  • GET /api/v1/payments/:id 查询支付与退款记录。
  • GET /api/v1/payments 游标分页列表，支持按状态筛选。
  • POST /api/v1/payments/:id/refund 部分或全额退款。
  • GET /api/v1/balance 可结算余额与在途结算。
  • GET/POST /api/v1/payouts 结算提现申请与记录。
  • 结账接口：GET /api/checkout/:token、POST /api/checkout/:token/pay、POST /api/checkout/:token/cancel。

Webhook

  • 事件 payment.succeeded 与 payment.refunded。
  • HMAC-SHA256 签名（X-SpacePay-Signature），6 次指数退避重试，后台可手动重投。
  • 投递前解析域名并拒绝内网目标。

商户后台与安全

  • 商户入驻审核、API Key 创建与吊销、Webhook 配置、支付与结算管理。
  • API Key 只保存哈希；每个 Key 独立限流；请求日志可追溯。
  • 付款人使用 httpOnly 会话与支付 PIN，可选 TOTP 两步验证。

文档

  • 文档站上线：快速开始、接口参考、Webhook、错误码、限流与幂等、密钥安全。
  • 所有接口提供 curl / Python / Node.js 示例。

兼容性说明

  • 接口路径与字段遵循语义化版本：新增字段属于兼容变更，删除或改名会提升主版本并在本页标注。
  • 金额字段同时提供整数分（*_cents）与十进制字符串，建议以整数分为准。
  • 错误响应的 code 是稳定标识，error 文案可能优化，请不要依赖文案匹配。
