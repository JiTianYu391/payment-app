结算余额与提现

查看商户可结算余额，申请把余额提现到指定账户。提现需财务审核，审核通过后出款（本环境为模拟出款）。

查询余额

GET/api/v1/balance需要 API Key
curl "https://your-domain/api/v1/balance" \
  -H "Authorization: Bearer $SPACEPAY_KEY"
import os
import requests

data = requests.get(
    "https://your-domain/api/v1/balance",
    headers={"Authorization": f"Bearer {os.environ['SPACEPAY_KEY']}"},
    timeout=15,
).json()
print(data["balance"]["available"])
const { balance } = await (await fetch('https://your-domain/api/v1/balance', {
  headers: { Authorization: `Bearer ${process.env.SPACEPAY_KEY}` },
})).json();
console.log(balance.available);
{
  "ok": true,
  "balance": {
    "available_cents": 1000,
    "available": "10.00",
    "pending_payout_cents": 0,
    "pending_payout": "0.00",
    "currency": "USD"
  }
}
字段说明
available_cents可结算余额 = 成功支付 − 已退款 − 已出款 − 审核中的提现
pending_payout_cents已申请、等待审核的提现金额

申请结算提现

POST/api/v1/payouts需要 API Key
参数类型说明
amount必填string提现金额，不能超过可结算余额
destination可选string收款账户说明，如 招商银行 尾号 1234
 
curl "https://your-domain/api/v1/payouts" \
  -X POST \
  -H "Authorization: Bearer $SPACEPAY_KEY" \
  -H "Content-Type: application/json" \
  -d '{"amount":"10.00","destination":"招商银行 尾号 1234"}'
import os
import requests

resp = requests.post(
    "https://your-domain/api/v1/payouts",
    headers={"Authorization": f"Bearer {os.environ['SPACEPAY_KEY']}"},
    json={"amount": "10.00", "destination": "招商银行 尾号 1234"},
    timeout=15,
)
print(resp.json())
const resp = await fetch('https://your-domain/api/v1/payouts', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${process.env.SPACEPAY_KEY}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({ amount: '10.00', destination: '招商银行 尾号 1234' }),
});
const data = await resp.json();
{
  "ok": true,
  "payout": {
    "id": "po_1",
    "numeric_id": 1,
    "amount_cents": 1000,
    "amount": "10.00",
    "status": "PENDING",
    "destination": "招商银行 尾号 1234",
    "created_at": 1762800300000
  }
}

提现状态

PENDINGSUCCEEDEDFAILED
状态说明
PENDING已提交，等待财务审核；金额已从可结算余额冻结
SUCCEEDED审核通过，已出款（模拟）
FAILED审核驳回，金额退回可结算余额

申请后金额立即从 available_cents 转入 pending_payout_cents，避免重复申请；驳回时自动退回。

查询提现记录

GET/api/v1/payouts需要 API Key

返回最近 50 条提现记录与当前余额。也可以在商户后台「结算」页查看并在页面内提交。

错误码

code原因
INSUFFICIENT_MERCHANT_BALANCE提现金额超过可结算余额
AMOUNT_REQUIRED未传金额
AMOUNT_INVALID金额格式错误
RATE_LIMITED请求过于频繁
!本环境的出款是模拟流程，不会到达真实银行账户。真实资金结算需要接入持牌支付机构。
