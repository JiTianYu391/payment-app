收款二维码

不必让顾客停留在 SpacePay 的结账页：用接口拿到二维码，直接展示在你的收银台、小程序、自助机或打印小票上。顾客用手机相机或 SpacePay「扫一扫」扫描，就会打开付款页。

i二维码内容就是 checkout_url，任何系统相机都能识别，不依赖本平台的客户端。二维码里不含密钥，可以安全地打印或投屏。

三种拿到二维码的方式

方式适合场景
payment.qr_svg
创建支付时直接返回		服务端渲染小票、生成 PDF、把 SVG 存进你自己的数据库
payment.qr.svg_url
图片地址		最简单：直接塞进 <img src>，手机端和桌面端都适用
GET /api/checkout/:token/qr需要在运行时换尺寸，或想一次拿到 payload 和 SVG 的场景

二维码 JSON 接口

GET/api/checkout/:token/qr公开接口，无需 API Key
参数类型说明
size可选integer输出尺寸（像素），96–1024，默认 256
 
curl "https://your-domain/api/checkout/$TOKEN/qr?size=320"
import requests

qr = requests.get(
    f"https://your-domain/api/checkout/{token}/qr",
    params={"size": 320},
    timeout=15,
).json()["qr"]

print(qr["payload"])   # 结账链接
open("pay.svg", "w", encoding="utf-8").write(qr["svg"])
const { qr } = await (await fetch(
  `https://your-domain/api/checkout/${token}/qr?size=320`,
)).json();

console.log(qr.payload); // 结账链接
fs.writeFileSync('pay.svg', qr.svg);

二维码图片

GET/api/checkout/:token/qr.svg返回 image/svg+xml

直接当图片地址用，不需要任何 SDK：

<img
  src="https://your-domain/api/checkout/AbCdEfGh…/qr.svg?size=320"
  width="320" height="320"
  alt="扫码付款">

SVG 是矢量格式，打印到小票或 A4 都不会糊；size 只影响 width/height 属性，矢量精度不受影响。

创建支付时一起拿到

POST /api/v1/payments 的响应里已经带好二维码，不需要再请求一次：

{
  "ok": true,
  "payment": {
    "id": "pay_42",
    "checkout_url": "https://your-domain/pay.html?token=AbCdEfGh…",
    "qr": {
      "payload": "https://your-domain/pay.html?token=AbCdEfGh…",
      "svg_url": "/api/checkout/AbCdEfGh…/qr.svg",
      "json_url": "/api/checkout/AbCdEfGh…/qr"
    },
    "qr_svg": "<svg xmlns=…>"
  }
}
!只有 CREATED 状态的支付单能出二维码。付款完成、取消或过期后接口返回 409 PAYMENT_NOT_PAYABLE，避免同一个码被重复收款。

二维码里到底是什么

默认是结账链接（https://your-domain/pay.html?token=…）。如果你的系统需要自己生成二维码，可以直接用 qr.payload，也可以用下面两种等价写法：

  • 结账链接：https://your-domain/pay.html?token=<token>
  • 深链：spacepay://pay/<token>
  • 裸 token：<token>（16–64 位 A-Z a-z 0-9 _ -）

SpacePay 的「扫一扫」三种都认；用系统相机扫时建议用结账链接那种，兼容性最好。

注意事项

  • payment.qr_svg 只在创建支付和查询单笔支付时返回；列表接口不带，避免响应过大。
  • 二维码接口是公开的（付款人不需要登录也能打开结账页），但 token 是 24 字节随机串，猜不到。
  • 不要把二维码图片缓存太久：支付完成后码就失效了，建议 max-age 不超过 60 秒。
  • 打印小票时保持四周至少 2 个模块的空白，太窄会扫不出来。
